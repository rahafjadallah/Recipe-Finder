### 🍽️ Recipe Finder

Discover delicious recipes and explore meals from around the world!
Recipe Finder is a web application built using HTML, CSS, and JavaScript that allows users to search for meals, view recipe details, explore ingredients, and follow cooking instructions using TheMealDB API.

## ✨ Features

- Search for meals by name.
- Fetch recipes dynamically using an external API.
- Display meal images and categories.
- View detailed recipe information.
- Display ingredients and their measurements.
- Read step-by-step cooking instructions.
- Watch cooking videos through YouTube links.
- Handle empty search inputs.
- Display error messages when no recipes are found.
- Responsive and user-friendly interface.

## 🌐 API Used

This project uses **TheMealDB API** to retrieve meal information and recipe details.

API Documentation:
https://www.themealdb.com/api.php

Main API Endpoints:

- Search meals by name:
  `search.php?s=chicken`

- Get meal details by ID:
  `lookup.php?i=52772`

---

## ⚙️ How It Works

1. Enter a meal name in the search field.
2. Click the search button or press Enter.
3. The application fetches matching meals from TheMealDB API.
4. Search results are displayed as meal cards.
5. Click on any meal to view its detailed recipe.
6. Explore ingredients, measurements, and cooking instructions.
7. Click the YouTube link to watch the cooking video if available.
